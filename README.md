# หนูน้อยหมวกแดงกับป่าโกงกาง

เกมนิทาน interactive ภาษาไทย ฉากแรก: สะพานขาด ภาพ SVG โทนพาสเทลพร้อมพื้นผิวคล้ายสีน้ำ ไม่ใช้บริการหรือไฟล์ภาพภายนอก

## วิธีเล่น

ดาวน์โหลด repository แล้วเปิด `index.html` ในเบราว์เซอร์สมัยใหม่ได้ทันที ไม่ต้องติดตั้ง dependency

- **กระโดดข้ามไป**: เดินถึงขอบสะพาน กระโดดเป็นเส้นโค้งไปอีกฝั่ง แล้วกดเดินต่อได้
- **เดินเลาะลงข้างล่าง**: เดินลงหาดเลน รองเท้าเปียก และพบปูก้ามดาบสองตัวประลองก้าม มีปุ่มดูเรื่องราวต่อ
- เริ่มใหม่ได้ทุกเวลา รวมถึงระหว่างแอนิเมชัน และเลือกลองอีกเส้นทางเมื่อจบ
- รองรับคีย์บอร์ด Tab / Enter, ขนาดจอมือถือ และการตั้งค่าลดการเคลื่อนไหว

ฉากนี้จบหลังข้ามสะพานหรือดูปู ไม่รวมฉากบ้านคุณยาย

## ตรวจสอบ

`node test.cjs` ทดสอบตรรกะสองเส้นทาง การเล่นต่อ การกดซ้ำ และการยกเลิกแอนิเมชันเมื่อเริ่มใหม่ ด้วย DOM จำลอง ไม่ใช่การทดสอบภาพในเบราว์เซอร์

ตรวจด้วยเบราว์เซอร์เพิ่มเติม: เล่นทั้งสองทาง ลองเริ่มใหม่ระหว่างกระโดด และตรวจหน้าจอมือถือกับคีย์บอร์ด
